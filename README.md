# 岩見沢 政治資金・新病院 公開データ

岩見沢市の新病院建設（事業費 約416.9億円）と、市長・市議・政党・業界団体の政治資金を、**公的記録だけ**で確認・整理した公開データセットです。

**これは告発ではなく、確認です。** 誰でも一次資料で追える事実を、出典つきで整理しました。評価・因果（「癒着」等）の断定はしません。事実と、その反対側の事実を併記します。

---

## 何が分かるか（要点）

- 新病院：工事費 約303.3億円（随意契約・ECI方式、R7.9.11）／全体事業費 約416.9億円。財源は企業債（借金）約371.7億＋国道補助39億＋その他6.2億。市民負担は一般会計繰入として R6 約9.6億→R9 約13.4億へ増の見通し（市の計画値）。
- 施工予定者＝大成建設札幌支店。ECI公募の応募は1者のみ。選定は外部学識2名＋市・病院職員6名の委員会（市議・政党関係者は不在）。
- 工事のJV構成企業18社のうち6社が、令和6年に自由民主党北海道岩見沢市第一支部（代表＝道議）への献金者と一致（社名・額・日付まで）。
- 市議関連で建設業の企業献金を受けるのは同第一支部のみ。市議個人の政治団体は多くが空報告。
- 業界政治連盟で外部（政治家）へ資金を出すのは建設・医療系。建設連盟→市長の資金管理団体／自民各支部・知事へ。市長の資金管理団体→市長本人の後援会へ500万円。

## 重要な線引き（必読）

- 上記はすべて公的記録に「記載がある」事実。**業界団体・政党が献金・支援すること自体は合法・一般的**であり、不正を意味しない。
- 「資金の重なり」と「新病院の契約・選定」を結ぶ因果は、これらの資料からは**言えない**。施工予定者を選んだのは献金を受けた政党・市議ではなく、外部委員を含む市の委員会。「地元業者への発注」は審査の公開された評価項目だった。献金時期は選定公表より前。
- 同姓同名（例：新川勝久・道下秀之）は本人確認が未了のものは「同名」と明記している。

## プライバシー方針

- **公人・政党・企業・業界団体は実名**（公的開示記録に基づく公益情報）。
- **私人（少額の個人献金者）は氏名を伏せ、件数・合計で集約**。企業の代表者個人名・住所も公開版から除外。
- 元PDF（全氏名を含む）は当データセットでは再ホストしない。一次資料は下記の公的機関の公表ページで確認できる。
